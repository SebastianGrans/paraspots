ParaSpots

A map of paragliding and hang gliding takeoff spots.

Using the map

  • Click a takeoff, on the map or in the list, to see its details
  • 📍 — use your current GPS location
  • Right-click the map (or long-press on mobile) to set a location manually
  • Once a location is set, sort the list by distance to find takeoffs near you

Keyboard shortcuts

  • / or Ctrl K — Focus search
  • Esc — Clear search
  • ↓ ↑ — Move through results
  • ? — Toggle this panel
